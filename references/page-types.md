# Page Types

- `concept`: a durable concept, protocol, framework, or method
- `entity`: a tool, product, company, person, or named system
- `source`: a one-to-one digest of a raw source
- `synthesis`: a cross-source or cross-discussion integrated page
- `map`: a topic map / MOC
- `overview`: compressed state of the current knowledge base
- `review`: structured backlog for uncertain issues and human decisions
- `purpose`: vault-level value judgment guidance for agents
- `log`: append-only maintenance log

Routing hints:

- one raw input -> `raw/` + `wiki/sources/`
- one durable idea -> `wiki/concepts/`
- one named thing -> `wiki/entities/`
- one cross-topic answer -> `wiki/syntheses/`
- one navigation hub -> `wiki/maps/`
- one current-state summary -> `wiki/overview.md`
- one uncertain issue or human decision -> `wiki/review.md`
- one value judgment guide -> `purpose.md`
- one maintenance log -> `wiki/log.md`
